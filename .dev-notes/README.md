# .dev-notes

Local-only design and architecture docs for ByTheBook. Like `AGENTS.md`, this folder is
gitignored.

The index of these docs, and when to read each one, is in `AGENTS.md` under "Read before
working on…". Keep that table as the only index.

- `architecture.md` explains why the system is built the way it is.
- `design/` holds one doc per feature or visualization, both live and candidate.
- `processes/` holds runtime call chains that span several files.
