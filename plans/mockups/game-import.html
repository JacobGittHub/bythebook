Importing games into the Library

The import as a guest would see it, following D29: the first three steps in a dialog, then the import running at the bottom of the Library's left page, under the books, where its report also lands. Pick "Done on another page" for the toast. "What scrolls" switches between the two answers to Q18. All names and numbers are examples.

Dialog first, then the page

Choosing, checking and the limit choice ask for the user's attention, so they are a dialog, as New book is. Once the import starts nothing more is asked, so the dialog closes and the work shows at the bottom of the left page. The user can open a book, the Explorer or anything else meanwhile; the app is a little slower until it finishes, since the import's worker shares the computer.

Q18 · What scrolls

  • B: the book list scrolls in its own space, and the import sits fixed at the bottom of the page, with a soft edge above it. Progress and the report stay in view however many books there are.
  • A: the whole left page scrolls, and the import is at the end of the list. Simpler, but with a long list the user has to scroll to see it, which defeats the point. Scroll the left page to see.

Finishing elsewhere

The import belongs to the dashboard, not the Library page, so moving between pages doesn't stop it. Finished while the user is on another page, it says so with a toast in the bottom right, with the way to the game history. The full report waits at the bottom of the Library until it is dismissed, then the section shrinks to the history's one-line summary ("Later visits").
